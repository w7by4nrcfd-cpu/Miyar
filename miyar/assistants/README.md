# miyar/assistants/

مساعدان مرجعيان يختبرهما مِعيار بمجموعة الاختبار نفسها (المقارنة المرجعية):

| المساعد | الوصف |
|---|---|
| `baseline` | نموذج لغوي عادي يجيب مباشرة |
| `rag` | النموذج نفسه مع بحث في المصادر المعتمدة فقط (`data/`) وإسناد |

- يُبنيان في **اليوم 1** من أيام التحدي (4 أكتوبر). المجلد فارغ في المرحلة 0 (هيكل فقط).
- ممنوع استخدام محرك الحكم الخاص بمِعيار (`judge.py`) داخل أي منهما.
