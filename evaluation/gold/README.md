# Gold Set: تحقق بشري نصي للاستشهادات القرآنية

**الحالة:** الأوراق المخفية جاهزة، والمراجعة البشرية لم تبدأ. لا وسوم ولا نتائج بعد. اتفاق أحكام مِعيار مع تقييمات بشرية: **لم يُقَس بعد**.

البروتوكول المسجّل مسبقاً: [PROTOCOL.md](PROTOCOL.md).

| الملف | المحتوى |
|---|---|
| `OFFICIAL_SHA256SUMS` | بصمات السجلات الرسمية ومخرجاتها المنشورة قبل Gold Set. اختبار يمنع أي تغيير عليها. |
| `quran/sheet_blind.md` و`.json` | الطبقة A: 31 استشهاداً قرآنياً بلا أحكام ولا معرّفات، بترتيب عشوائي |
| `quran/key.json` | ربط كل عنصر بالجولة والحالة ورقم الاستشهاد، بلا أحكام. لا يفتحه المراجع. |
| `behaviour/sheet_blind.md` و`.json` | الطبقة B (اختيارية): 16 إجابة للحالات الحرجة الأربع في الجولات الأربع |
| `behaviour/key.json` | ربط عناصر الطبقة B، بلا أحكام |
| `<layer>/labels.json`، `LOCK.json`، `agreement.json` | تُنشأ لاحقاً فقط: بعد المراجعة الفعلية، ثم القفل، ثم الحساب |

```
python scripts/gold_set.py extract          # قابل للتكرار؛ يتحقق من البصمات ولا يكتبها فوق القديمة
python scripts/gold_set.py lock quran       # بعد إدخال الوسوم الفعلية فقط
python scripts/gold_set.py compute quran    # بعد القفل فقط؛ أعداد ومقامات بلا نسب
```

## الحدود

- هذا ليس مراجعة شرعية، ولا تحققاً عاماً من مِعيار.
- المراجع في الطبقة A هو صاحب المشروع (`owner_textual`): غير مستقل، وقد رأى أحكام مِعيار من قبل.
- الأحاديث خارج هذه الطبقة.
