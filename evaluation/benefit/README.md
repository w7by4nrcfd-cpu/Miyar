# Benefit Benchmark: التحقق النصي يدوياً مقابل بمساعدة مِعيار

**الحالة:** التجربة مسجّلة مسبقاً ومقفلة. لم تُجرَ أي جلسة قياس، ولا بيانات خام، ولا نتائج.

البروتوكول: [PROTOCOL.md](PROTOCOL.md).

| الملف | المحتوى |
|---|---|
| `PREREGISTRATION.json` | البذرة، وبصمات البروتوكول والعناصر والتوزيع ومخرجات مِعيار والأداتين والكود والسجلات المحمية، وبصمة المفتاح |
| `items_blind.json` | 28 عنصراً (24 + 4 إحماء): المقطع والموضع فقط، مع التنبيه الموحّد بأنها محفزات اختبار وبعضها مقطع معدل عمداً |
| `assignment.json` | التوزيع المقفل: لكل مراجع (r1، وr2 الاختياري) كل `item_id` وموضعه وحالته (A/B) وكتلته |
| `miyar_outputs.json` | مخرجات `judge_citation` الحقيقية لكل عنصر (بلا نموذج لغوي) |
| `tool/review_r1.html`، `tool/review_r2.html` | أداة الجلسة والتوقيت لكل مراجع؛ فيها مخرجات مِعيار لعناصر الحالة B فقط |
| `key.json` | **غير موجود بعد**: يُكتب بعد قفل البيانات الخام فقط، ويطابق `key_sha256` |

```
python scripts/benefit_benchmark.py verify       # البصمات لم تتغير والمفتاح المُعاد توليده يطابق بصمته
python scripts/benefit_benchmark.py lock r1      # بعد الجلسة فقط
python scripts/benefit_benchmark.py reveal-key   # بعد القفل فقط
python scripts/benefit_benchmark.py compute r1   # بعد القفل وكشف المفتاح فقط
```

**ما ليست هذه التجربة:**
- ليست مراجعة شرعية.
- لا تشمل الأحاديث ولا السلوك.
- العناصر محفزات اختبار لا تُعرض في الموقع.
