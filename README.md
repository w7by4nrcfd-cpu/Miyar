# مِعيار (Mi'yar)

**مِعيار يختبر المساعد الذكي نفسه، لا نصاً مفرداً.** يطرح على المساعد مجموعة أسئلة موسومة
بمستويات المحتوى (A–D)، ثم يتحقق من إسنادات كل إجابة، ويفحص التزامه بالسلوك المطلوب لكل
مستوى، ويصدر درجة موثوقية ومقارنة بين النماذج وقرار نشر أو منع (بوابة جودة).

> مشاركة في تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي 2026 (مؤسسة باذل) —
> المسار 04: أدوات المعرفة والتحقق لتمكين المعرّفين بالإسلام.

## المقارنة المرجعية
يُشغّل مِعيار مجموعة الاختبار نفسها على مساعدين بالنموذج نفسه: **baseline** (يجيب مباشرة) و**rag**
(يبحث في المصادر المعتمدة ويُسند)، ويعرض الدرجة الكلية ودرجة كل مستوى وعدد الإسنادات الخاطئة
وسلوك الامتناع والإحالة. (يُبنى في أيام التحدي.)

## الحالة الحالية
المشروع في **المرحلة 0 (البنية التحتية)** فقط. انظر [BASELINE.md](BASELINE.md) لقائمة
دقيقة بما هو جاهز قبل أيام التحدي، و[CHANGELOG.md](CHANGELOG.md) لما يُنجز يوماً بيوم.

رابط التجربة المباشرة: _يُضاف بعد النشر خلال أيام التحدي._

## المبادئ
- كل رقم معروض ناتج عن تشغيل فعلي مسجّل في `evaluation/` مع عدد الحالات (N).
- الحكم الآلي مساعد للمراجعة البشرية لا بديل عنها؛ ويُعرض عدد الحالات المراجَعة بصدق.
- لا حكم «مؤيَّد» دون مطابقة مصدر فعلية في البيانات؛ غياب المرجع = «يحتاج تحقق».
- مِعيار لا يولّد آية ولا حديثاً ولا حكماً؛ كل نص شرعي يُعرض منقول من بيانات لها مصدر.
- مطابقة نص القرآن برمجية حرفية (بعد توحيد التشكيل والهمزات) دون نموذج لغوي.

## التشغيل
```bash
pip install -r requirements.txt
python -m pytest -q                          # اختبارات بايثون
node --test tests/web/*.test.mjs             # منطق صفحة النتائج
python -m http.server 8000 --directory web   # معاينة الموقع: http://localhost:8000
uvicorn miyar.api:app --port 8001            # الخلفية: /health فقط
```
النشر الثابت على Cloudflare Pages: [docs/DEPLOY.md](docs/DEPLOY.md).

## التقنيات
Python 3.11 · FastAPI (هيكل `/health` فقط) · HTML/CSS/JS بلا أدوات بناء · pytest · Node 22 (`node --test`) · GitHub Actions · نص Tanzil 1.0.2 ·
بيانات الصحيحين من fawazahmed0/hadith-api. التفاصيل والإصدارات في [ARCHITECTURE.md](ARCHITECTURE.md).

|---|---|---|
| Claude Code | كتابة الكود والاختبارات والتوثيق في أثناء التطوير | استُخدم فعلاً |
| Claude | التخطيط والتطوير | استُخدم فعلاً |
| Gemini | مخطط استخدامه **داخل المنتج** في أيام التحدي (4–6 أكتوبر 2026) | **لم يُستدعَ بعد** |

مِعيار نفسه لا يستدعي حالياً أي نموذج لغوي. مطابقة الآيات برمجية حرفية دون نموذج لغوي.
