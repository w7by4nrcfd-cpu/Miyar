# مِعيار (Mi'yar)

**مِعيار يختبر المساعد الذكي نفسه، لا نصاً مفرداً.** يطرح على المساعد مجموعة أسئلة موسومة
بمستويات المحتوى (A–D)، ثم يتحقق من إسنادات كل إجابة، ويفحص التزامه بالسلوك المطلوب لكل
مستوى، ويصدر درجة موثوقية ومقارنة بين مساعدين وقرار نشر أو منع (بوابة جودة).

> مشاركة في تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي 2026 (مؤسسة باذل) —
> المسار 04: أدوات المعرفة والتحقق لتمكين المعرّفين بالإسلام.

**رابط التجربة المباشرة:** <https://miyar.w7by4nrcfd.workers.dev>. موقع ثابت على Cloudflare Workers بوضع «نتائج محفوظة»
(لا استدعاء لأي نموذج من الموقع). التشغيل الحي من الواجهة حُذف من الخطة بقرار صاحب المشروع (2026-10-04).

## كيف يعمل
1. **المساعد المُختبَر يجيب** عن حالات الاختبار (`runner` + `assistants`): **baseline** يجيب مباشرة، و**rag** هو النموذج نفسه
   مع بحث محلي في المصادر المعتمدة فقط (آيات Quranpedia ومدخلات الملف اليدوي المكتملة).
2. **الاستخراج** (`extract`): نموذج مِعيار يستخرج الآيات والأحاديث من الإجابة، ثم تحقق برمجي يرفض أي نص أو موضع لم يرد فيها.
3. **حكم الإسناد برمجياً بلا نموذج لغوي:** الآيات حرفياً مع Quranpedia (`quran_match`)، والأحاديث مع الملف اليدوي وحده (`hadith_match`).
4. **حكم السلوك** (`judge`): الحَكَم يطبّق السلوك المتوقع وفحوص الحالة مع درجة ثقة؛ وما دون العتبة يُحال إلى مراجعة بشرية بلا حكم آلي.
   وكل خطأ يُصنَّف في **أصناف الحكم الستة** (مختلق، منسوب خطأً، محرَّف، ناقص التوثيق، سلوك خاطئ في المستوى، رفض غير لازم).
5. **الدرجة والمقارنة والبوابة** (`scoring`): درجة لكل مستوى مع N، ومقارنة baseline بـ rag، وقرار نشر أو حجب بقاعدة مكتوبة.
6. **السجل والنشر:** `python -m miyar.evaluate` يكتب السجل الكامل، و`scripts/publish_results.py` يحسب منه أرقام الموقع.

## المبادئ
- كل رقم معروض ناتج عن تشغيل فعلي مسجّل في `evaluation/official/` مع عدد الحالات (N).
- الحكم الآلي مساعد للمراجعة البشرية لا بديل عنها؛ ويُعرض عدد الحالات المراجَعة بصدق لكل نوع.
- لا حكم «مؤيَّد» دون مطابقة مصدر فعلية في البيانات؛ غياب المرجع = «يحتاج تحقق».
- مِعيار لا يولّد آية ولا حديثاً ولا حكماً؛ كل نص شرعي يُعرض منقول من بيانات لها مصدر.
- مطابقة نص القرآن برمجية حرفية (بعد توحيد التشكيل والهمزات) دون نموذج لغوي.

## التشغيل
```bash
pip install -r requirements.txt
python -m pytest -q                          # اختبارات بايثون
node --test tests/web/*.test.mjs             # منطق الموقع واختبارات المتصفح (Playwright إن توفر)
python -m http.server 8000 --directory web   # معاينة الموقع: http://localhost:8000
python -m miyar.evaluate --assistant baseline --cases official_v0 --label DEV_RUN   # تشغيل تطوير (يحتاج مفتاحاً ووضع live)
python scripts/publish_results.py --check    # تزامن web/data/ مع evaluation/official/
```
الإعدادات كلها في متغيرات بيئة (`.env.example`)، ولا مفاتيح في المستودع. الوضع الافتراضي `cached` لا يستدعي أي نموذج.
النشر الثابت على Cloudflare Workers (وليس Pages): [docs/DEPLOY.md](docs/DEPLOY.md).

## الحدود المعروفة
- **لا مراجع شرعي مختص:** لم تُجرَ مراجعة شرعية متخصصة لأي حالة (`specialist`: 0). المراجعة المسجّلة تحقق مصادر (`source_check`) يجريه المشارك، وليست مراجعة شرعية.
  والسلوك المتوقع في كل حالة من إعداد المشروع. الحكم الآلي مساعد للمراجعة لا بديل عنها، وقد يخطئ في السلوك الشرعي.
- **مدخلات الأحاديث:** التحقق يعتمد على ملف يدوي (`data/hadith/manual_hadith.json`) فيه 9 مدخلات، 8 مكتملة؛
  و H-009 (EXT-042) ينقصه الرابط، فحالته تُحال إلى مراجعة بشرية بلا حكم آلي.
  ونفي وجود حديث في الصحيحين مكتوب في ملاحظات المدخل لا في حقل منظّم، فالنسبة الخاطئة إلى البخاري أو مسلم تُحكم «يحتاج تحقق» لا «خاطئ».
  ولا تُستخدم أي مجموعة أحاديث خارجية؛ المجموعة السابقة معزولة في `data/unapproved/hadith/`.
- **فرق الرسم «مرضاة» / «مرضات»:** التوحيد يحوّل التاء المربوطة هاءً ويُبقي المفتوحة تاءً، فقد تُحكم آية منقولة برسم إملائي
  مختلف بـ `wrong_or_missing` مع أنه فرق رسم لا تحريف (لوحظ في التحريم 1 في تشغيل تطوير). لم يُعدَّل `normalize` بقرار صاحب المشروع.
- **تحيّز مقارنة rag:** مدخلات الأحاديث اليدوية التي يسترجعها rag أُعدّت لحالات الاختبار نفسها، فالمقارنة تميل لصالحه.
- **N محدود:** التشغيلات الرسمية على 12 حالة (`official_v0`)، فلا تُعمَّم الأرقام. كل رقم معروض مع N.
- **حصة النماذج المجانية:** حدود الطلبات اليومية في الخطة المجانية ضيّقة، فقد لا يتسع تشغيل كامل في يوم واحد؛ والحالة التي يتعذّر حكمها تُسجَّل ولا تُحتسب في الدرجة.
- **نص القرآن:** الملف العثماني المعروض يصف نفسه في المصدر بأنه «غير موافق للمطبوع»، والإملائي بأنه «موافق لطبعة مجمع الملك فهد»؛ الوصفان من المصدر ولم نتحقق منهما مستقلاً.
- **بلا تشغيل حي من الواجهة:** الموقع يعرض نتائج محفوظة فقط.
