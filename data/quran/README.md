# نص القرآن الكريم — Tanzil

| الملف | النوع | الاستخدام في مِعيار |
|---|---|---|
| `quran-uthmani.txt` | الرسم العثماني، مشكول (`سورة|آية|نص`) | عرض النص الموثّق للمستخدم |
| `quran-simple.xml` | الرسم الإملائي، مشكول | المطابقة الحرفية بعد التوحيد |

- المصدر: مشروع Tanzil — https://tanzil.net — الإصدار 1.0.2، ترخيص Creative Commons Attribution 3.0.
- **الملفات منسوخة حرفياً دون أي تعديل** (شرط الترخيص)، مع كتلة حقوق Tanzil داخل كل ملف.
- كل توحيد أو فهرسة تتم في الذاكرة وقت التشغيل (`miyar/quran_match.py`) ولا تُكتب فوق هذه الملفات.
- بصمات SHA-256 في `SHA256SUMS` للتحقق من سلامة الملفات.
