# بيانات الأحاديث

## 1. الصحيحان

`sahihayn.jsonl.gz`: سطر JSON لكل حديث (14,940 حديثاً: البخاري 7,580 + مسلم 7,360).

| الحقل | المعنى |
|---|---|
| `id` | معرّف فريد داخل مِعيار (`bukhari:1`) |
| `collection` / `collection_ar` | الكتاب |
| `number` | رقم الحديث المتداول (ترقيم فؤاد عبد الباقي لمسلم؛ قد يتكرر لروايات متعددة تحت رقم واحد) |
| `book`, `in_book` | الكتاب والرقم داخله حسب ترقيم المصدر |
| `text` | النص العربي بالسند كما في المصدر |
| `grade` | `صحيح` |
| `grade_basis` | `collection`: الحكم مستفاد من كون الحديث في أحد الصحيحين |
| `source` | المصدر والإصدار المثبّت |

- المصدر والترخيص: انظر SOURCES.md (fawazahmed0/hadith-api — Unlicense).
- حُذفت المدخلات ذات النص الفارغ في المصدر (9 للبخاري، 203 لمسلم).
- إعادة التوليد: `python scripts/build_hadith_data.py` (ناتج حتمي).
- ملف محلي بالكامل: لا اعتماد وقت التشغيل على أي واجهة خارجية.

## 2. أحاديث لا تصح (مجموعة اختبار صغيرة)
`weak_fabricated.json`: 6 أحاديث مشتهرة لا تصح نسبتها إلى النبي ﷺ، لكل منها حكمان لعالمين
(الحكم بنصه، الكتاب، الصفحة أو الرقم، ورابط التحقق على dorar.net).

| الحقل | المعنى |
|---|---|
| `id` | `WF-01` … |
| `text` | صيغة مختصرة غير مشكولة، مطابقة حرفياً لـ `dorar_text` بعد التوحيد وحذف المسافات (مختبرة) |
| `status` | `not_authentic`: لا يصح عن النبي ﷺ بحسب الأحكام المنقولة |
| `rulings[]` | `scholar`، `ruling`، `book`، `page_or_number`، `narrator`، `dorar_text`، `verify_url` |
| `review_status` / `reviewed_by` | `pending` حتى تراجعها جهة مختصة |

- الغرض: اختبار مقاومة المساعد للاختلاق والنسبة الخاطئة (مثل OFF-06)، لا عرض أحكام حديثية للمستخدم كمرجع نهائي.
- لا يرد أي منها في بيانات الصحيحين المحلية (مختبر).
